# VNE ACO Baseline

This directory implements a standalone Ant Colony Optimization baseline for the
VNE problem instances generated by `vne/`.

ACO is not a neural training route. It uses a small solved supervised subset to
tune search hyperparameters, then solves the validation dataset with the chosen
fixed parameters.

## Flow

```text
supervised solved subset
  -> tune ACO parameters

validation dataset
  -> solve with fixed ACO parameters
  -> compare against ILP labels when available
```

## Run

Edit paths and values in `vne_aco/config.py`, then run:

```bash
python -m vne_aco.cli
```

## Formulation

The ACO action matches the current VNE trajectory action:

```text
current virtual link -> choose one feasible substrate path
```

The objective also matches VNE:

```text
cost = sum(virtual bandwidth demand * substrate path hop count)
objective = -cost
```

Higher objective is better because it means lower embedding cost.

## Current Constraint

ACO currently supports the embed-all formulation only:

```text
enable_admission = False
```

Admission/rejection should be added later only after the main VNE trajectory
also supports acceptance-aware actions.
